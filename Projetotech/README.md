# 🎉 Eventos Gratuitos de Brasília 2026

## 📋 Descrição do Projeto

**Eventos Gratuitos de Brasília 2026** é uma plataforma web moderna e intuitiva que centraliza informações sobre eventos gratuitos acontecendo em Brasília durante o ano de 2026. O site oferece uma experiência de usuário otimizada para descobrir, filtrar e se manter atualizado sobre as melhores atividades gratuitas da capital federal.

## ✨ Características Principais

- 📅 **Calendário Interativo**: Visualize eventos por data, categoria ou local
- 🔍 **Filtros Avançados**: Busque por tipo de evento, bairro, dias da semana
- ❤️ **Favoritos**: Salve eventos para acompanhar depois
- 📱 **Responsivo**: Funciona perfeitamente em dispositivos móveis, tablets e computadores
- 🔔 **Notificações**: Receba alertas sobre novos eventos e atualizações
- 📍 **Mapa Interativo**: Localize eventos próximos de você
- 📊 **Recomendações Personalizadas**: Sugestões baseadas nas suas preferências

## 🎯 Objetivos

- Democratizar o acesso à informação sobre eventos culturais, educacionais e recreativos gratuitos
- Reduzir tempo de busca por atividades interessantes em Brasília
- Estimular a participação em eventos comunitários
- Criar um espaço colaborativo onde usuários compartilhem suas experiências

## 🚀 Como Começar

### Pré-requisitos
- Navegador web moderno (Chrome, Firefox, Safari, Edge)
- Git instalado
- Node.js (versão 14 ou superior)

### Instalação

1. Clone o repositório:
```bash
git clone https://github.com/adrianoabc786-prog/EngenhariaDePrompt_AplicacoesAI.git
cd EngenhariaDePrompt_AplicacoesAI/Projetotech
```

2. Instale as dependências:
```bash
npm install
```

3. Inicie o servidor local:
```bash
npm start
```

4. Abra seu navegador em:
```
http://localhost:3000
```
